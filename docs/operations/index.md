# Operations

Choose the runtime and control workflow before beginning an experiment.

- [SITL](sitl.md) — start, inspect, and stop the PX4/Gazebo environment.
- [Companion](companion.md) — run the physical-aircraft companion services.
- [Onboard](onboard.md) — select native PX4 control and execute an uploaded trajectory.
- [Offboard](offboard.md) — run ROS 2 control and manage PX4 handback.
- [Tools](tools.md) — command terminals, communication paths, and analysis utilities.
