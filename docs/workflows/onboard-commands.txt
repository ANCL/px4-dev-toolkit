PX4 native SE3 — command contexts
=================================

See docs/operations/onboard.md for the full procedure.
These commands are not an unattended flight script.

UBUNTU TOOLKIT SHELL ($)
-----------------------
./tools/sitl start
# On the configured companion: ./tools/hardware start

# Independent DDS recording, started before mode selection:
source ros2/runtime_env.sh
./tools/px4_record onboard_se3

PX4 SHELL (pxh> / nsh>)
----------------------
# Inspect the built-in SE3 module and trajectory settings:
se3_control status
param show TRJ_HOME_Z
param show TRJ_HOME_YAW
param show TRJ_F8_T
logger status

# Take off using the prepared pilot/SITL procedure.
# Only proceed when airborne, stable, and the intended NED origin is verified.
# Optional example, if intended and suitable: param set TRJ_HOME_Z -2.5
se3_control select
se3_control status
# Require active=1, faulted=0, holding
se3_control trajectory figure_eight_tracking
se3_control status
# To interrupt: se3_control hold

# Return through the pilot's Position-mode control.
# In SITL: commander mode posctl
# Confirm Position mode; land and disarm.

ANALYSIS WORKSTATION ($)
------------------------
source ros2/runtime_env.sh
./tools/px4_analyze bags/onboard_se3/<recording-directory>
# Analyze a separately obtained finalized PX4 ULog:
./tools/px4_analyze /path/to/flight.ulg --profile onboard_se3

NOTES
-----
- No .traj files, YAML compilation or MAVLink FTP upload are involved.
- Native trajectories are firmware-defined and configured with TRJ_* parameters.
- ROS 2 Offboard trajectories remain separately configured in config/trajectories.yaml.
- The onboard catalog is absolute PX4 local NED; no pose alignment occurs.
- The mode captures measured pose on entry and on explicit hold.
- The MAVLink link supports the PX4 shell; native parameters are managed within PX4.
- DDS recordings and ULogs contain different native execution metadata.
